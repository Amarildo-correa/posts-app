Guia interativo sobre terminal, linguagens e comandos para desenvolvedores iniciantes

conceito
O terminal é uma interface de texto para o sistema operacional
Tudo que você faz com o mouse em uma interface gráfica — abrir pasta, mover arquivo, iniciar programa — o terminal faz com texto e ENTER.
C:\projetos\posts-app> docker compose up -d
✓ Container mysql_master Started
✓ Container mysql_replica Started
✓ Container app_posts Started
O terminal é como um chat com o sistema operacional. Você digita uma instrução, o sistema executa e responde.
você digita
docker compose up -d
sistema responde
Container Started ✓
estrutura
Todo comando tem partes com responsabilidades diferentes
docker compose -f docker-compose.yml up --build -d
docker
o programa sendo executado — como abrir um aplicativo
compose
o subcomando — diz qual parte do docker você quer usar
-f arquivo
flag com valor — especifica qual arquivo usar
up
a ação — o que você quer fazer (subir containers)
--build -d
modificadores — rebuild da imagem e modo background
flags com -- são palavras completas  ·  flags com - são atalhos de uma letra
--build = reconstruir  |  -d = detached (background)
conceito
A extensão do arquivo define quem vai interpretar e executar o código
.js
JavaScript
interpretado pelo Node.js — lógica do servidor, rotas, models
node server.js  ← Node.js lê e executa
.sql
SQL
interpretado pelo MySQL — criação de tabelas, queries, índices
mysql -u root -p 001_criar_tabelas.sql
.yml
YAML
interpretado pelo Docker Compose — define serviços, volumes, redes
docker compose -f docker-compose.yml up
.bash
Shell script
interpretado pelo terminal — automatiza sequências de comandos
bash deploy.bash  ← terminal lê e executa linha por linha
comparação
Terminal é rascunho — arquivo é código de produção
terminal — uma vez
> GRANT SELECT ON
posts_app_db.*
TO 'posts_user'@'%';
executa → some → esquece
arquivo — para sempre
002_privilegios.sql
GRANT SELECT ON
posts_app_db.*
TO 'posts_user'@'%';
salvo → versionado → reproduzível
↓
Fluxo profissional: testa no terminal → valida o resultado → salva no arquivo → commita no git
o ENTER em cada contexto
terminal
você aperta ENTER — executa imediatamente
migrate.js
Node.js aperta ENTER — envia cada linha pro MySQL
docker compose
Docker aperta ENTER — monta cada serviço
nodemon
nodemon aperta ENTER — reinicia o servidor
quiz — teste o que aprendeu
